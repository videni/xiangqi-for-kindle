# PW4 象棋：KPM 与专注对局

用户确认：PW4，固件 5.18；只有 KPM。以下包含 2026-11-16 后续确认的交互收敛方案。

## 范围与方案

基于上游 Kindle v0.1.3，保留 GTK2/Cairo、棋子素材、象棋规则和 Pikafish。增加 KPM 分发与隐藏式菜单。原来常驻悔棋的备选布局已由用户排除；重写渲染器会增加触摸、显示和运行库风险，本次沿用已有实现。

## 对局交互

- 主屏：完整棋盘，顶部显示“红方走棋”或“黑方走棋”。恢复成功先显示“已恢复上次对局”，两秒后切回当前走棋方；不拼接其他状态或显示手数。
- 从底边上滑、轻点顶部状态或棋盘上下留白，打开同一个底部菜单；下滑或点棋盘收起，并消费本次手势，不落子。
- 顶边向下滑唤出 Kindle 原生快捷设置；系统顶部栏不常驻。
- 棋盘点击在抬手后生效；滑动超过阈值后不能再成为点击。无论是否轮到玩家，菜单手势均可用。
- 白底菜单仅一排“新局、悔棋、退出”，细线分隔。菜单和新局面板悬浮在棋盘上；不变更棋盘的位置、大小，也不加深色遮罩。
- 新局提供“我执红、我执黑、双人对弈”，取消自动演示。使用白底单选标记；双人对弈隐藏电脑难度。确认开始才改变当前棋局，取消保留当前棋局。
- 退出自动保存，启动自动载入。删除手动保存、载入、棋谱入口，保留悔棋及存档所需的内部历史。
- 不做动画或持续刷新；提示使用一次性两秒计时器。

## KPM 与数据

- 输出 manifest v2 的 kindlehf `.kpkg`，包含应用、ARM 运行库、现有 ARM32 Pikafish 及 NNUE。
- 安装创建书库脚本入口，入口调用 `kpm launch`，不要求 KUAL。
- 启动路径从包目录解析，不依赖旧 extensions 固定路径。保存位置独立于升级时替换的包文件。
- 升级保留棋局；卸载仅删除本包拥有的入口，保留玩家存档。
- 提供可本地安装的包；用户另已授权推送到个人 fork，并通过 Wi-Fi 更新 Kindle。

## 验证边界

手势分类测试覆盖点击、底边上滑、普通拖动、非底边上滑、重复点击与菜单收起。包测试执行真实 hooks，覆盖首次安装、升级、卸载以及用户改过的同名入口。运行现有引擎 smoke test。

在 Linux/GTK2 中执行真实 UI 点击和拖动，检查 1072×1448 的主屏与菜单截图；构建 ARMv7 包并验证归档、ELF 与资源。每次更新的真机安装、触控手感、墨水屏残影和实际 Pikafish 耗时单独报告，不用本地测试代替。
