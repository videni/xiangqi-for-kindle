# PW4 象棋：KPM 与专注对局

用户确认：PW4，固件 5.18；只有 KPM。主界面只留棋盘、状态、菜单，菜单向上滑动时才出现。

## 范围与方案

基于上游 Kindle v0.1.3，保留 GTK2/Cairo、棋子素材、象棋规则和 Pikafish。增加 KPM 分发与隐藏式菜单。原来常驻悔棋的备选布局已由用户排除；重写渲染器会增加触摸、显示和运行库风险，本次沿用已有实现。

## 对局交互

- 主屏：一行简短中文状态，其余空间给棋盘。没有常驻按钮、标题、引擎信息或棋谱侧栏。
- 从底边上滑打开菜单；下滑或点棋盘空白区域收起，并消费本次手势，不落子。
- 棋盘点击在抬手后生效；滑动超过阈值后不能再成为点击。无论是否轮到玩家，菜单手势均可用。
- 菜单提供新局、悔棋、保存、载入、棋谱、退出；模式与难度放在新局设置中，确认开始才改变当前棋局。
- 棋谱只在主动查看时出现；关闭后返回当前对局，不能停留在不可落子的隐藏历史状态。
- 不做动画或持续刷新；显示菜单和收起菜单各完成一次重排。

## KPM 与数据

- 输出 manifest v2 的 kindlehf `.kpkg`，包含应用、ARM 运行库、现有 ARM32 Pikafish 及 NNUE。
- 安装创建书库脚本入口，入口调用 `kpm launch`，不要求 KUAL。
- 启动路径从包目录解析，不依赖旧 extensions 固定路径。保存位置独立于升级时替换的包文件。
- 升级保留棋局；卸载仅删除本包拥有的入口，保留玩家存档。
- 提供可本地安装的包；上线软件源、发布到 GitHub 不属于本次授权。

## 验证边界

手势分类测试覆盖点击、底边上滑、普通拖动、非底边上滑、重复点击与菜单收起。包测试执行真实 hooks，覆盖首次安装、升级、卸载以及用户改过的同名入口。运行现有引擎 smoke test。

在 Linux/GTK2 中执行真实 UI 点击和拖动，检查 1072×1448 的主屏与菜单截图；构建 ARMv7 包并验证归档、ELF 与资源。尚未连接用户 Kindle，真机安装、触控手感、墨水屏残影和实际 Pikafish 耗时单独报告。
